# Adobe_internship
Project Title: React Multi-Page App

Description:
This is a responsive web application built with React. It supports multiple pages using React Router, manages global state with the Context API, and saves user data in the browser’s local storage. The UI is styled using Tailwind CSS for a clean and modern look.

Main Features:

Navigation between pages using React Router

Global state management with Context API

Welcome page with login and registration options

User data is stored in local storage

Functional footer that allows page switching

Fully responsive design for mobile and desktop


How to Run the Project:

First, clone the project from GitHub.

Open the terminal and navigate to the project folder.

Run npm install to install all the required packages.

Then run npm start to start the development server.
